# 贪吃蛇

入口：小游戏乐园 → 贪吃蛇。直接用 Xcode 编译 My_Study，无需新增依赖或执行 RN 命令。

14 × 18 格棋盘，吃一颗果实得一分并增长一格；每三分提升速度，速度有上限。撞墙或撞自己结束，填满棋盘获胜。最佳成绩保存在本机。

圆形方向键按下立即提交转向，蛇会自动前进；也可以在棋盘上滑动转向。快速转弯最多缓存两个方向，按移动步数依次执行，禁止直接掉头。

初次进入或重开后点击“开始”；暂停/继续由右侧按钮控制。离开页面、锁屏、进入后台或系统打断会停掉计时器，回到页面后手动继续。游戏内侧滑返回保持禁用。

```sh
clang -std=c11 -O1 -g -Wall -Wextra -Werror -fsanitize=address,undefined "tests/CRMSnakeRulesTests.c" -o "/private/tmp/crm-snake-tests"

```

直接测试应用共用规则，覆盖移动、成长、食物不占蛇身、方向缓冲、反向输入、撞墙撞身、进入腾出的尾格、满盘通关、重开及 2000 局随机游玩。

## 真机验收

- 检查安全区域和圆形方向按钮；开始前、暂停后蛇应静止。
- 点击开始，方向键和棋盘滑动均能控制转弯；快速连按不应直接掉头。
- 吃果实后加分增长，每三分逐步加速，重开后恢复初始速度。
- 撞墙/撞身显示结束提示，可重新开始；关闭再打开应用仍保留最佳成绩。
- 拉出控制中心、切后台、锁屏、返回游戏中心后均应暂停，不能后台继续移动。
