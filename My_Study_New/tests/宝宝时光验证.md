# 胎教与宝宝时光验证

## 当前实现

首页首张卡片进入「胎教与宝宝时光」。五个栏目分别是胎教、阅读、声音、手记和出生后。
胎教以孕周主题、日常聊天、朗读与音乐为主；出生后入口保留面对面交流、共读与成长记录。
首次使用设置产检确认的预产期，出生后再手动记录出生日期。日期只用于内容切换，不作医疗判断。

目前内置 18—40 周共 23 个陪伴主题、65 篇孕期原创朗读、36 篇出生后原创短文、130 个聊天话题和 14 段离线合成旋律。
「阅读」中另有 38 期《洛克菲勒写给孩子的38封信》播客索引，每期提供原创共读角度、父母反思问题、收藏和 Apple 播客单集入口。节目音频及平台文字在原平台查看；系列书信的史料真实性尚未核实，界面以播客观点呈现，不当作已证实的历史原信。
朗读支持分类、收藏、大字阅读、分页浏览及系统中文语音朗读，可选择设备已安装的普通话声音和两档语速；音色列表排除 Apple「个人声音」，朗读仅在设备内实时播放，不保存或导出系统语音。声音支持播放、录音、导入、定时停止，页面内还有音乐下载站入口；手记支持文字、照片、录音与 ZIP 导出。
录音最长 3 分钟，切到后台自动结束；用户需自行选择有权使用的导入音频。
备份 ZIP 包含 `journal.json` 和照片、音频附件，建议导出后存入用户选择的安全位置。

内容定位为父母与宝宝的互动灵感。孕 18 周听觉仍在发育，不要求胎儿回应；不要把耳机或音箱贴在腹部。
依据：[NHS 孕 18 周](https://www.nhs.uk/best-start-in-life/pregnancy/week-by-week-guide-to-pregnancy/2nd-trimester/week-18/)、
[Essex NHS 孕期对话、唱歌与阅读](https://www.eput.nhs.uk/services/childrens-speech-language-therapy/universal-support-for-speech-language-and-communication-development-from-birth/bump/)。

## 自动化验证

在仓库根目录执行：

```sh
clang -fobjc-arc -framework Foundation \
  "My_Study_New/My_Study/Business/BabyTime/CRMBabyStore.m" \
  "My_Study_New/My_Study/Business/BabyTime/CRMBabyContent.m" \
  "My_Study_New/tests/CRMBabyTimeTests.m" \
  -o "/private/tmp/babytime-store-tests"
"/private/tmp/babytime-store-tests"
```

覆盖孕周跨夏令时和闰年、出生日期手动切换、内容完整性、收藏、手记存储恢复、
非法日期、损坏数据保护、附件路径、ZIP 导出。测试进程应在 60 秒内完成。
ZIP 使用 Python `zipfile.testzip()` 验证 CRC 和附件字节数。

音频资源可复现：

```sh
python3 "My_Study_New/scripts/generate_babytime_audio.py"
```

如需更新项目资源引用，可运行 `ruby "My_Study_New/scripts/register_babytime_resources.rb"`。
外部音乐建议从 Pixabay Music 或 Musopen 挑选，下载后存入「文件」并从 App 导入；逐首查看授权说明，不把下载的录音直接打包分发。

iOS 模拟器编译：

```sh
xcodebuild -workspace "My_Study_New/My_Study.xcworkspace" \
  -scheme "My_Study" -configuration Debug -sdk iphonesimulator \
  -destination "generic/platform=iOS Simulator" \
  -derivedDataPath "/private/tmp/babytime-derived" \
  CODE_SIGNING_ALLOWED=NO build
```

## 手工验收

1. 首页第一张卡片打开胎教页，确认没有触发首页原有网络演示请求。
2. 设置预产期，检查孕周和对应周主题；跨天重进页面后日期更新。
3. 打开孕期朗读，检查分类、收藏、大字阅读和「再看一些」；在文章页试听系统朗读、暂停继续、切换声音及语速、停止和返回自动停止；切换到出生后检查 36 篇共读短文。
4. 切换到「家书播客」，确认按第 1—38 期排序、可分页浏览和收藏。打开第 1、19、38 期，检查导读与父母问题；点「打开这期播客」应进入对应单集。系统朗读只读导读，不播放或复制节目音频。
5. 播放 14 段内置音频，验证暂停、停止、定时停止、耳机拔出和来电中断；检查两个音乐网站入口及导入说明。
6. 授予麦克风权限后录音，结束后在声音小屋与手记中看到记录；拒绝权限时看到提示。
7. 导入音频，检查不支持格式、50 MB 上限与失败提示。
8. 写文字和照片手记，重启后确认内容；导出 ZIP 并查看其中的 JSON 和附件。
9. 手动登记出生日期后重进模块，默认显示「出生后」；孕期记录与朗读仍可回看。
10. 检查深色模式、大字体和窄屏设备上的五个栏目与卡片布局。
