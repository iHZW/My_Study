# 戏曲TV

面向小米电视等 Android TV 设备的极简戏曲观看应用。内置 WebView 打开各大戏曲网站，遥控器方向键即可操作。

## 功能

- 主页菜单：CCTV空中剧院 / 中国戏曲像音像集萃 / 央视网戏曲频道 / 看戏网
- 自定义网址：输入任意网址打开观看
- 观看历史：自动记录看过的页面，可设置上限（50/100/200/500），超限自动清理最旧记录，可一键清空
- 遥控器方向键按页面位置选择视频卡片、链接和播放器按钮，黄色描边显示当前焦点
- 遥控器确认键打开当前选项，播放/暂停键控制页面中的主要视频
- 遇到无法选中的网页控件时，按遥控器菜单、信息、指南或设置键开启光标模式；方向键移动、确认键点击、返回键退出
- 光标模式下轻按方向键会精细移动，按住方向键会逐级加速，便于选中全屏、音量等小按钮
- 焦点框会自动淡出，光标点击后立即隐藏，进入全屏播放时不会遮挡视频
- 视频全屏播放，返回键先退出全屏、再退网页、最后退出页面

## 构建

用 Android Studio（ Hedgehog 及以上）打开本目录，等待 Gradle 同步完成后：

- **Run** 到已连接的电视 / 模拟器，或
- **Build > Build APK(s)** 生成 `app/build/outputs/apk/debug/app-debug.apk`

也可以命令行构建（需本机有 Android SDK，sdk.dir 写入 `local.properties`）：

```bash
gradle wrapper   # 首次生成 wrapper
./gradlew assembleDebug
```

## 安装到小米电视

任选其一：

1. **U盘**：把 apk 拷到 U盘插电视，用电视的文件管理器安装（需在设置中允许"安装未知来源应用"）
2. **adb**：电视与电脑同一 WiFi，电视开启开发者选项和 USB 调试后：
   ```bash
   adb connect <电视IP>:5555
   adb install app-debug.apk
   ```

## 说明

- minSdk 21（Android 5.0+），小米电视全系可装
- 纯系统框架，无第三方依赖
- 视频解码依赖电视的 WebView 内核，个别网站若提示无法播放，可尝试在电视上更新"Android System WebView"
